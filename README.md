# Basis_model
# Basismodel website

Een herbruikbaar basismodel voor websites van kleine zaken, gebouwd tijdens mijn opleiding full stack developer.

## Doel
Eén basismodel dat daarna aangepast wordt voor drie zaken:
1. Een schrijnwerkerij (massieve vloeren en trappen)
2. Een algemene karweizaak
3. Een kinepraktijk (neurokine en bekkenbodem)

## Technologie
- Dit semester: HTML, CSS (variabelen, BEM, mobile-first) en JavaScript
- Later: TypeScript, Node.js/Express en MongoDB voor formulieren en aanvragen

## Lokaal starten
Open `index.html` met de VS Code-extensie Live Server.
